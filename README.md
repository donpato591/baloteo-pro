# Baloteo Pro - Web App

Sistema oficial de gestión de torneos, cotejo, pesaje y baloteo en tiempo real conectado con **Supabase** y listo para desplegar en **Vercel**.

## 🚀 Despliegue en Vercel (1 Clic)

1. Sube el contenido de esta carpeta a tu repositorio de **GitHub**.
2. Entra en [Vercel](https://vercel.com) y selecciona **Add New... -> Project**.
3. Selecciona tu repositorio de GitHub.
4. En **Framework Preset**, déjalo en **Other** (o Static Site).
5. Haz clic en **Deploy**. ¡Tu web app estará en línea con HTTPS gratis!

## 📦 Contenido de esta carpeta

- **`index.html`**: Archivo maestro único de la aplicación web.
- **`vercel.json`**: Configuración de enrutamiento estático para Vercel.
- **`.gitignore`**: Exclusión de archivos temporales para Git.
- **`README.md`**: Guía rápida de uso y despliegue.
